# 隐私政策

生效日期：2026 年 11 月 25 日。

本政策说明 ReUBAA 如何处理学校账号、会话、业务数据、邮箱、提醒和更新检查。ReUBAA 没有自己的服务器，不收集、不上传你的个人信息。

## 开发者信息

应用名称：ReUBAA。开发者：kahpoh19（个人维护）。

ReUBAA 是基于开源项目 [UBAA](https://github.com/BUAASubnet/UBAA) 修改的个人版本，与 UBAA 原开发者 BUAASubnet 无隶属关系，也与北京航空航天大学官方无隶属或授权关系。

## 学校账号与业务请求

**登录所需的账号、密码与验证码只用于向学校认证系统验证身份。**课表、成绩、作业、预约和云盘等请求由设备通过直连或学校 WebVPN 发起，不经过 ReUBAA 或 UBAA 的任何服务器。

登录过程产生的会话与 Cookie 用于后续访问学校系统。**选择阳光打卡照片并提交时，照片会上传到学校业务系统。**

## 北航邮箱

使用邮箱功能时，应用通过 IMAP/SMTP 直接连接北航邮箱服务器收发邮件，不经过其他服务器。邮箱地址和客户端专用密码保存在设备安全存储中，退出邮箱时删除。

## 设备上的保存

- 勾选记住密码后，应用通过设备安全存储保存相应凭据，供后续登录使用。
- 应用保留本地会话与配置，以恢复登录和连接状态。
- 业务数据可能保存在加密缓存中，用于再次打开或离线查看。
- 页面偏好和本地账号信息用于恢复使用状态。外观主题是独立的设备偏好，保存在普通本地偏好存储中，不包含账号凭据，也不随退出或清除账号删除。
- 添加桌面课表组件后，应用会在本机保存一份课表副本，供组件在应用未打开时显示。

设置页提供缓存清理、退出登录及清除已保存账号等操作，作用范围以操作提示为准。

## 提醒与后台运行

课程与待办提醒默认关闭。开启后，应用根据本机已有的课表和待办，在设备上排定系统本地通知，不使用任何推送服务器。

开启需要在后台运行的功能后，应用会在后台保持运行，Android 通知栏会常驻一条“后台运行中”的通知，期间的请求同样由设备直接发往学校系统。可以随时在设置中关闭。

## 更新检查

打开应用后以及在关于页手动检查时，应用会向 GitHub 的公开接口查询 ReUBAA 的最新版本；下载更新时从 GitHub 获取安装包。请求不携带学校账号、Cookie 或任何用户标识，但 GitHub 会按其自身规则处理网络地址等访问信息。选择忽略的版本号保存在普通本地偏好存储中。

## 产品改进统计

ReUBAA 不提供产品改进统计和应用内公告，也不连接 UBAA 的应用服务，不会上传使用情况、错误记录或任何标识。

## 本次运行诊断

本地诊断保存最近七天内最多 100 条错误记录，用于定位读取、提交和启动的失败阶段和原因。完整诊断报告和本地错误编号不会自动上传。反馈问题前请检查拟发送的文字和截图。

## 同意与数据删除

首次使用或本政策更新后，需要阅读并同意本政策才能登录。

ReUBAA 不提供独立账号注册，开发者也不保存你的任何个人信息。退出登录并清除已保存账号，即可删除本机账号数据。

## 联系维护者

如对本政策有疑问，请通过 ReUBAA 的 [GitHub Issues](https://github.com/kahpoh19/ReUBAA/issues) 联系维护者，不要反馈到 UBAA 原项目。请勿在公开渠道发布账号、密码、验证码、预约门锁信息或个人资料。
